Update Google Apps Script Bridge

Bridge Needs Redeployment
The Google Apps Script Web App endpoint is currently running the older single-file bridge, so it cannot index folder contents or subfolders.

Follow these steps to enable folder scanning and large-PDF downloads:

  1. Open your script at script.google.com.
  2. Replace all contents of Code.gs with the recursive bridge script:
  3. In Project Settings, enable Show "appsscript.json" manifest file. In its oauthScopes array, include: https://www.googleapis.com/auth/drive.readonly and https://www.googleapis.com/auth/script.external_request. The repository's appsscript.json has these scopes; merge them with any existing scopes.
  4. Save, select authorizeBridge in the function menu, click Run, and approve the requested Drive and external-request permissions.
  5. Click Deploy → Manage deployments → Edit (pencil icon), select "New version", ensure access is "Anyone", and click Deploy.
